Ghibli-Inspired Narrative Map

Ghibli-Inspired Narrative Map — Design artistic com ghibli, watercolor, narrative. Template e prompt pronto para IA.

ghibliwatercolornarrativemapsoftpaintednaturemagicstory

Uso: Landing pages, Websites modernas

Contexto Histórico

Estilo Ghibli-Inspired Narrative Map representa uma tendência moderna em design UI/UX web com foco em artistic.

Quando Usar

Use quando seu produto precisa parecer feito à mão e sem pressa. Apps infantis onde encantamento importa mais que eficiência. Plataformas de storytelling onde a interface em si é parte da narrativa. Ferramentas educacionais que recompensam curiosidade acima de conclusão. Jogos de aventura onde exploração É a mecânica. Evite para dashboards, ferramentas enterprise ou qualquer coisa onde usuários precisam de velocidade acima de atmosfera. Esse padrão pede que as pessoas desacelerem — tenha certeza de que é isso que você realmente quer.

Princípios de Design

  • Imperfeição como intenção — pinceladas visíveis, bordas sangradas e textura de papel sinalizam artesanato humano sobre precisão de máquina
  • Revelação progressiva através de geografia — esconda complexidade atrás de terreno; deixe usuários descobrirem features explorando o mapa em vez de escaneando uma lista
  • Profundidade atmosférica sobre hierarquia flat — use névoa, luz e parallax em camadas para comunicar o que é acessível agora versus o que está adiante
  • Paleta contida, emoção máxima — limite-se a 4-5 matizes aquarela por cena; deixe white space e grain de papel fazerem o trabalho pesado
  • Movimento segue a natureza — animações referenciam vento, água e crescimento em vez de easing mecânico; nada estala, tudo assenta

## Layout

- **Spacing rhythm:** Balanced. Base unit: 0.5rem (8px).
- **Section vertical gaps:** clamp(4rem, 8vw, 8rem).

- **Feature sections:** Zig-zag alternating text+image rows. No 3-equal-columns.
- **Mobile collapse:** All multi-column layouts collapse below 768px. No horizontal overflow.
- **z-index contract:** base (0) / sticky-nav (100) / overlay (200) / modal (300) / toast (500).

## Elevation & Depth

Digital watercolor with soft outlines, character vignettes, organic connecting paths, soft diffuse natural light, warm ambient glow.

- **Physics:** Ease-out curves, 200-300ms duration. Smooth and predictable.
- **Entry animations:** Fade + translate-Y (16px → 0) over 420ms ease-out. Staggered cascades for lists: 80ms between items.
- **Hover states:** Subtle color shift + shadow adjustment over 200ms.
- **Page transitions:** Fade only (200ms).
- **Performance:** Only transform and opacity animated. No layout-triggering properties.

## Shapes

Base corner radius: 15px. See rounded tokens in front matter for the full scale.

## Components

- **Primary Button:** Rounded (15px) shape. Accent color fill. Hover: 8% darken + subtle lift shadow. Active: -1px translate tactile press. Font weight 600. No outer glows.
- **Secondary / Ghost Button:** Outline variant. 1.5px border in muted color. Text in primary color. Hover: subtle background fill.
- **Cards:** Rounded (15px) corners. Surface background. Subtle shadow (0 2px 12px rgba(0,0,0,0.06)). 1px border stroke.
- **Inputs:** Label above input. 1px border stroke. Focus ring: 2px accent color offset 2px. Error text below in semantic red. No floating labels.
- **Navigation:** Primary surface background. Active item: accent color indicator. Font weight 500 when active.
- **Skeletons:** Shimmer animation matching component dimensions. No circular spinners.
- **Empty States:** Icon-based composition with descriptive text and action button.

## Do's and Don'ts

- No emojis in UI — use icon system only (Lucide, Heroicons)
- No pure black (#000000) — use off-black or charcoal variants
- No oversaturated accent colors (saturation cap: 80%)
- No 3-column equal-width feature layouts — use zig-zag or asymmetric grid
- No `h-screen` — use `min-h-[100dvh]`
- No AI copywriting clichés: "Elevate", "Seamless", "Unleash", "Next-Gen"
- No broken external image links — use picsum.photos or inline SVG
- No generic lorem ipsum in demos

## Regras de Execução

1. Siga fielmente o estilo visual determinado.
2. Use ícones SVG inline de alta qualidade (estilo Heroicons ou Lucide) — PROIBIDO usar emojis como ícones.
3. Adicione `cursor-pointer` e estados de `hover` suaves (transition-all) em todos os elementos interativos.
4. Estrutura Obrigatória da Página:
   - Navbar (Logo + Links + CTA)
   - Hero Section (Headline impactante + Subtitle + 2 botões + Elemento visual 3D/Abstrato via CSS)
   - Features (3 cards com ícones)
   - Testimonials (3 cards)
   - Pricing (3 tiers, destaque no central)
   - CTA Final
   - Footer completo com redes sociais, política de privacidade, termos de uso, contato e links SEO.
5. Todo o conteúdo textual deve ser em Português Brasileiro (PT-BR).
6. O visual deve ser CLARAMENTE distinto — não crie um design "padrão Bootstrap". Force o uso das variáveis de design system fornecidas.
7. Use tags `<style>` no head para classes personalizadas (especialmente para os efeitos complexos de backdrop-filter e animações) que o Tailwind via CDN não cobrir.
8. Responsividade Total: O layout deve se adaptar perfeitamente a Mobile, Tablet e Desktop (Stack vertical no mobile).
9. Inclua meta tags básicas de SEO, Viewport e Open Graph no `<head>`.
10. Footer deve conter: Copyright 2026, Links de navegação secundária e Ícones de redes sociais.
11. Assuma as decisões criativas necessárias para entregar o resultado completo e funcional agora.
